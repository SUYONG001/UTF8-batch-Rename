UTF-8 批量重命名工具 - 使用说明
============================================================

【工具说明】
- 通过 Python 解析标准批处理命令，解决 Windows 原生 bat 脚本因 ANSI 编码导致无法识别 UTF-8 特殊字符的问题。
- 支持针对纯文件以及文件夹进行批量重命名。

【环境准备】
- 使用前需安装 Python 环境，安装界面必须勾选 "Add Python to PATH"。
- Python 官方网站：https://www.python.org/

【文件构成】
1. Rename.py   : 执行脚本，双击即可全自动运行。
2. Rename.txt  : 待执行的命令列表文件，必须保存为 UTF-8 编码。
3. Rename.xlsx : Excel 辅助生成模板，用于快速拼接命令文本。

【编写规范】
- 命令格式：遵循标准 ren 语法，即 ren "原名称" "新名称"。
- 批量生成：可在 Excel 中使用公式快速拼接，例如：
  ="ren "&""""&A1&""""&" "&""""&B1&" - "&C1&".mkv"""
- 导出注意：将 Excel 生成的列复制粘贴到 Rename.txt 中保存，务必确认编码选择为 UTF-8。

【使用方法】
1. 将 Rename.py 与编辑好的 Rename.txt 一同放置在需要重命名文件的目标文件夹内。
2. 鼠标双击运行 Rename.py 脚本即可完成处理。
