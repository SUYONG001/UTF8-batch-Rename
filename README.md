# 🏷️ UTF-8 批量重命名工具使用指南

> **核心特性**：解决 Windows 原生批处理（`.bat`）因 ANSI 编码限制而无法正确支持 UTF-8 编码及特殊字符的问题[cite: 4]，支持对文件与文件夹进行批量重命名[cite: 4]。

---

## 一、 工具优势与解决痛点

* **突破 ANSI 编码限制**：Windows 系统的 `cmd.exe` 批处理默认依赖 ANSI 编码，面对日文假名、生僻字、特殊符号或多语言混排时极易出现乱码或重命名失败[cite: 4]。
* **原生 UTF-8 支持**：通过 Python 解析 UTF-8 编码的命令文本，完美识别并处理各类包含特殊字符的文件名[cite: 4]。
* **兼容原生批处理逻辑**：沿用标准的 `ren "原文件名" "新文件名"` 命令格式，学习成本为零[cite: 4]。
* **全类型兼容**：同时支持对纯文件以及文件夹进行批量命名更替[cite: 4]。

---

## 二、 环境准备（新设备只需配置一次）

1. **下载与安装 Python**：
   * 访问 [Python 官方网站](https://www.python.org/) 下载安装程序[cite: 4]。
   * **关键步骤**：安装界面务必勾选 **`Add Python to PATH`**（将 Python 添加到系统环境变量）[cite: 4]。
2. **验证环境**：
   * 按键盘 <kbd>Win</kbd> + <kbd>R</kbd> 键输入 `cmd` 并回车。
   * 输入 `python --version`，若能正常返回版本号即说明环境配置成功。

---

## 三、 文件构成与职责说明

| 文件名 | 格式/编码 | 说明与职责 |
| :--- | :--- | :--- |
| **`Rename.py`** | Python 源码 | 核心执行脚本，双击即可全自动运行[cite: 4]。 |
| **`Rename.txt`** | 纯文本 (**UTF-8**) | 存放重命名指令清单，需严格保持 UTF-8 编码[cite: 4]。 |
| **`Rename.xlsx`** | Excel 表格 | 辅助模板，用于快速批量拼接并生成指令文本[cite: 4]。 |

---

## 四、 重命名指令编写规范

### 1. 基础语法格式
在 `Rename.txt` 中，每行一条标准的 `ren` 命令，原文件名与新文件名均建议使用英文双引号包裹[cite: 4]：

```bat
ren "原文件名" "新文件名"
```

* **示例**：
  ```bat
  ren "Episode_01.mkv" "第01话.mkv"
  ren "Old_Folder_Name" "New_Folder_Name"
  ```

---

### 2. 利用 Excel 高效批量生成指令
处理几十上百个文件时，可使用配套的 `Rename.xlsx` 通过公式一键拉取生成内容[cite: 4]：

#### 推荐公式
假设 **A列** 为原文件名，**B列** 为集数编号，**C列** 为章节标题，在 **D列** 输入：

```excel
="ren "&""""&A1&""""&" "&""""&B1&" - "&C1&".mkv"""
```
[cite: 4]

#### 公式拆解说明
* `="ren "`：拼接批处理命令前缀[cite: 4]。
* `&""""&`：在文本中插入转义的双引号 `"`。
* 最终生成效果：`ren "原文件" "B1 - C1.mkv"`[cite: 4]。

> **生成后导出**：在 Excel 中选中生成的整列，复制后粘贴到 `Rename.txt` 中保存（**保存时务必确认文件编码选择为 UTF-8**）[cite: 4]。

---

## 五、 操作流程

1. **就位脚本**：将编辑好的 `Rename.txt` 与 `Rename.py` 一同放入需要修改文件的目标文件夹内[cite: 4]。
2. **执行处理**：鼠标双击 `Rename.py` 脚本[cite: 4]。
3. **完成验收**：脚本会自动按行读取指令并完成重命名，遇到乱码字符与特殊字符均能平稳处理[cite: 4]。
